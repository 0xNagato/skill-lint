# Needs work

This skill demonstrates the most common real-world failure, and it is a warning
rather than an error because nothing here is *broken* — the file parses, the
skill loads, and it will simply never be chosen.

The description above says what the skill *is* ("powerful", "flexible",
"advanced") and never says when to use it. There is no trigger the router can
match a user request against, so this skill sits in the library looking healthy
and never fires. Its author concludes that skills don't work.

Compare with `../good-skill/SKILL.md`, which ends on an explicit
"Use when the user asks to …" clause.
